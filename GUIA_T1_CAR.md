# Guia do Trabalho 1 (T1) - CRUD de carros

Este guia resume o que deve existir no projeto para entregar o T1: uma API REST com CRUD completo para a entidade `Car`.

## 1. Dependências do Spring Boot

No arquivo `api/pom.xml`, o projeto precisa destas dependências:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-webmvc</artifactId>
</dependency>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-flyway</artifactId>
</dependency>

<dependency>
    <groupId>org.flywaydb</groupId>
    <artifactId>flyway-database-postgresql</artifactId>
</dependency>

<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

Elas permitem criar endpoints HTTP, mapear classes Java para tabelas, executar migrations automaticamente e conectar ao PostgreSQL.

## 2. Migration do banco de dados

Criar o arquivo `api/src/main/resources/db/migration/V2__create_cars.sql` com a tabela de carros:

```sql
CREATE TABLE cars (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    color TEXT NOT NULL,
    year_manufacture INTEGER NOT NULL,
    imported BOOLEAN NOT NULL,
    plates TEXT NOT NULL,
    selling_date DATE,
    selling_price NUMERIC(12,2),
    customer_id BIGINT,

    CONSTRAINT pk_cars PRIMARY KEY (id),
    CONSTRAINT uq_cars_plates UNIQUE (plates),
    CONSTRAINT fk_cars_customer
        FOREIGN KEY (customer_id)
        REFERENCES customers(id)
);
```

Importante: a aplicação deve estar parada ao criar ou editar uma migration já inexistente. Depois, execute a aplicação para o Flyway aplicar a `V2`.

## 3. Entidade `Car`

Criar `api/src/main/java/.../entities/Car.java`. A classe representa a tabela `cars` e deve usar `@Entity` e `@Table(name = "cars")`.

Os atributos Java e seus campos no banco são:

| Atributo Java | Coluna SQL | Tipo Java | Obrigatório |
| --- | --- | --- | --- |
| `id` | `id` | `Long` | Gerado pelo banco |
| `brand` | `brand` | `String` | Sim |
| `model` | `model` | `String` | Sim |
| `color` | `color` | `String` | Sim |
| `yearManufacture` | `year_manufacture` | `Integer` | Sim |
| `imported` | `imported` | `Boolean` | Sim |
| `plates` | `plates` | `String` | Sim e único |
| `sellingDate` | `selling_date` | `LocalDate` | Não |
| `sellingPrice` | `selling_price` | `BigDecimal` | Não |
| `customerId` | `customer_id` | `Long` | Não |

Para os nomes que diferem entre Java e SQL, use `@Column(name = "...")`. Exemplo:

```java
@Column(name = "year_manufacture", nullable = false)
private Integer yearManufacture;

@Column(name = "selling_date")
private LocalDate sellingDate;

@Column(name = "selling_price", precision = 12, scale = 2)
private BigDecimal sellingPrice;

@Column(name = "customer_id")
private Long customerId;
```

Inclua construtor sem argumentos, getters e setters para todos os atributos. Os nomes em camelCase são importantes: permitem receber os JSONs solicitados, por exemplo `yearManufacture` e `sellingDate`.

## 4. Repository

Criar `api/src/main/java/.../repositories/CarRepository.java`:

```java
package dr.edu.fatecfranca.api.repositories;

import org.springframework.data.jpa.repository.JpaRepository;
import dr.edu.fatecfranca.api.entities.Car;

public interface CarRepository extends JpaRepository<Car, Long> {
}
```

Caso o projeto use outro nome de pacote, manter o mesmo pacote-base usado pelas demais classes. O `JpaRepository` já fornece `save`, `findAll`, `findById`, `existsById` e `deleteById`.

## 5. Controller e endpoints

Criar `api/src/main/java/.../controllers/CarController.java`, anotado com:

```java
@RestController
@RequestMapping("/cars")
```

Injetar `CarRepository` pelo construtor e implementar estes endpoints:

| Operação | Método e rota | Resultado de sucesso | Caso não exista |
| --- | --- | --- | --- |
| Criar | `POST /cars` | `201 Created` e carro salvo | Erro de validação/banco se dados inválidos |
| Listar todos | `GET /cars` | `200 OK` e lista de carros | Retorna lista vazia se não houver registros |
| Buscar um | `GET /cars/{id}` | `200 OK` e carro | `404 Not Found` |
| Atualizar por completo | `PUT /cars/{id}` | `200 OK` e carro atualizado | `404 Not Found` |
| Excluir | `DELETE /cars/{id}` | `204 No Content` | `404 Not Found` |

Modelo dos métodos principais:

```java
@PostMapping
public ResponseEntity<Car> create(@RequestBody Car car) {
    Car savedCar = repository.save(car);
    return ResponseEntity.status(HttpStatus.CREATED).body(savedCar);
}

@GetMapping
public List<Car> findAll() {
    return repository.findAll();
}

@GetMapping("/{id}")
public ResponseEntity<Car> findById(@PathVariable Long id) {
    return repository.findById(id)
            .map(ResponseEntity::ok)
            .orElse(ResponseEntity.notFound().build());
}

@PutMapping("/{id}")
public ResponseEntity<Car> update(@PathVariable Long id, @RequestBody Car car) {
    if (!repository.existsById(id)) {
        return ResponseEntity.notFound().build();
    }
    car.setId(id);
    return ResponseEntity.ok(repository.save(car));
}

@DeleteMapping("/{id}")
public ResponseEntity<Void> delete(@PathVariable Long id) {
    if (!repository.existsById(id)) {
        return ResponseEntity.notFound().build();
    }
    repository.deleteById(id);
    return ResponseEntity.noContent().build();
}
```

## 6. Payloads para teste

Inicie a API na pasta `api`:

```bash
./mvnw spring-boot:run
```

Use a URL-base `http://localhost:8888/cars` no EchoAPI, Postman, Insomnia ou outro cliente HTTP.

### Primeiro POST

Requer que já exista um cliente com `id` igual a `1`:

```json
{
  "brand": "Toyota",
  "model": "Corolla XEi",
  "color": "Prata",
  "yearManufacture": 2022,
  "imported": false,
  "plates": "ABC1D23",
  "sellingDate": "2026-09-10",
  "sellingPrice": 128500.00,
  "customerId": 1
}
```

Resposta esperada: `201 Created`.

Depois, testar `GET /cars`: devem aparecer os dois registros com status `200 OK`.
